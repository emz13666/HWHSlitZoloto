# HWH Слить золото (Дар стихий / Аврора)

[![Version](https://img.shields.io/badge/version-0.7-blue.svg)](https://raw.githubusercontent.com/emz13666/HWHSlitZoloto/main/HWHSlitZoloto.user.js)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Пользовательский скрипт (UserScript) для браузерной игры **Hero Wars**, который расширяет функционал популярного помощника **HeroWarsHelper (HWH)**. Скрипт добавляет в меню "Действия" новые кнопки для автоматизации работы с Даром стихий Авроры и скрытыми покупками.

## ✨ Возможности

### 1. 🔥 Слить золото
Автоматизирует прокачку Дара стихий Авроры пакетами для эффективного "слива" золота.
- Выполняет указанное пользователем количество циклов.
- Каждый цикл: сбрасывает Дар стихий (если уровень > 0), затем отправляет пакет из 30 вызовов повышения уровня (0 → 30).
- **Важно**: После завершения последнего цикла Дар стихий остается на 30 уровне.
- Стоимость одного цикла: **7 927 500 золота**.

### 2. 🛒 Невидимый магазин
Позволяет совершить заданное количество скрытых покупок в специальном магазине.
- Использует игровой вызов `shopBuy` с параметрами `shopId: 18`, `slot: 1`.
- Стоимость одной покупки: **3 000 000 золота**.

## 📋 Требования

- Установленный и работающий менеджер пользовательских скриптов: **Tampermonkey**, **Violentmonkey** или аналогичный.
- Установленное и активное расширение **HeroWarsHelper** (версии **v2.460** и выше). Скрипт использует его глобальные объекты (`HWHData`, `Caller`, `cheats`).
- Браузер с доступом к одной из поддерживаемых версий игры:
  - `https://www.hero-wars.com/*`
  - `https://www.hero-wars.cn/*`
  - `https://apps-1701433570146040.apps.fbsbx.com/*`

## 📥 Установка

1. Установите расширение для управления скриптами (например, [Tampermonkey](https://www.tampermonkey.net/)).
2. Убедитесь, что у вас установлен и корректно работает **HeroWarsHelper**.
3. Перейдите по прямой ссылке на скрипт:  
   👉 [Установить HWHSlitZoloto](https://raw.githubusercontent.com/emz13666/HWHSlitZoloto/main/HWHSlitZoloto.user.js)
4. Нажмите кнопку **"Установить"** (Install) в открывшемся окне менеджера скриптов.
5. Обновите страницу с игрой Hero Wars.

## 🎮 Использование

1. Откройте игру Hero Wars и дождитесь полной загрузки.
2. Активируйте меню **HeroWarsHelper**.
3. Перейдите в раздел **"Действия"** (Actions).
4. Вы увидите две новые кнопки:
   - **"Слить золото"**: нажмите, введите желаемое количество циклов и подтвердите. Скрипт покажет прогресс-бар и возможность экстренной остановки.
   - **"Невидимый магазин"**: нажмите, введите количество покупок и подтвердите.
5. После завершения операции появится модальное окно с итогами (количество выполненных действий и потраченное золото).

## ⚙️ Технические детали

- **Задержка между действиями**: 100 мс для прокачки дара, 200 мс для покупок в магазине (для снижения нагрузки на сервер и имитации естественных задержек).
- **Обработка ошибок**: При возникновении ошибки во время цикла скрипт попытается сбросить Дар стихий до уровня 0, чтобы избежать застревания в промежуточном состоянии, и выведет сообщение об ошибке.
- **Поиск героя**: Скрипт автоматически ищет героя с именем, содержащим "Аврора" или "Aurora" (через вызов `heroGetAll` и перевод имен).
